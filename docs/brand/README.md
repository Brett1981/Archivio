# Metaroq brand foundation

## Brand core

- **Name:** Metaroq
- **Flagship tagline:** Media that finally makes sense.
- **Essence:** Intelligent organisation for complex media collections.
- **Mission:** Turn scattered media files into a clear, trustworthy library that can be reviewed once and organised safely at scale.
- **Value proposition:** Metaroq combines local file evidence, embedded metadata, online sources, and explainable automation plans without changing media until the user has reviewed and approved the outcome.

## Visual identity

The selected identity is the **Weave Grid**: a connected metadata-node mark with a single Soft Aqua node. It represents files becoming linked, understood, and structured.

Primary assets:

- `metaroq-selected-concept.png` — approved visual direction and reference board.
- `../../src/Archivio.App/Assets/Branding/metaroq-icon.png` — production 1024 px app-icon master.
- `../../src/Archivio.App/Assets/Branding/metaroq.ico` — Windows multi-size icon.

### Palette

| Role | Name | Value |
| --- | --- | --- |
| Foundation | Deep Slate | `#1F1F2A` |
| Primary action | Meta Blue | `#3A6CF0` |
| Positive intelligence | Soft Aqua | `#7FE0D6` |
| Human accent | Warm Sand | `#E8D7C5` |
| Neutral contrast | Graphite | `#2C2C2C` |

Use Deep Slate for the product shell, Meta Blue for primary actions and analysis, Soft Aqua for confident or complete states, and Warm Sand sparingly for decisions and human attention.

### Typography

- Product UI: Segoe UI for native Windows clarity and zero bundled-font licensing risk.
- Brand and marketing: Inter or Montserrat may be used under their respective open-font licences when packaged with the licence text.
- Prefer sentence case, short labels, and a clear information hierarchy.

### Logo rules

- Keep clear space around the mark equal to one node diameter.
- Minimum icon size: 16 px; use the supplied Windows icon sizes rather than resizing the concept board.
- Use the full-colour mark on Deep Slate or white backgrounds.
- Do not distort, rotate, recolour individual nodes, add shadows, or rebuild the mark from text glyphs.

## Voice and tone

Metaroq is confident, precise, and reassuring. Explain what the system knows, why it believes it, and what will happen next. Prefer strong verbs and plain language.

Good: “Review 11 metadata warnings before approval.”

Avoid: “The system encountered anomalous metadata conditions.”

## Product naming

Use **Metaroq** for the desktop product until separate editions genuinely exist. Reserve descriptive names such as Metaroq Index, Flow, Sync, and Cloud for real, distinct capabilities rather than using them decoratively.

## Ownership and legal checklist

Initial exact-name web and registry checks found no obvious Metaroq software brand conflict, and the `.com` registry returned no active registration at the time checked. These results are encouraging but are not legal clearance and can change at any time.

Before public launch:

1. Register the priority domain and matching defensive domains through the owner's preferred registrar.
2. Reserve matching source-control, social, package, and app-store identifiers.
3. Run formal clearance searches in the UK IPO, EUIPO/TMview, and relevant international jurisdictions, including similar-sounding marks.
4. Ask a qualified trade-mark professional to review the intended goods and services, especially software classes 9 and 42.
5. File the chosen word mark and, once stable, the figurative/logo mark.
6. Keep dated copies of the selected concept, source prompts, generated masters, and first commercial-use evidence.

No domain purchase, account reservation, or trade-mark filing is performed by the application build.

## Asset-generation record

The production icon was created with the built-in image-generation workflow using the approved concept board as the exact visual reference. The prompt requested the selected Weave Grid connected-node mark, white nodes with a Soft Aqua lower-right node, a Deep Slate rounded-square tile, transparent outer background, no text, no shadow, and legibility at 16 px. The generated master was then losslessly prepared into PNG and multi-size ICO deliverables.
